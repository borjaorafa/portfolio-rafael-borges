# Rafael Borges · Portfólio profissional

Versão V10.2, pronta para hospedagem estática em GitHub Pages. Design responsivo em português, identidade escura e roxa e arquivos HTML/CSS/JS sem build obrigatório.

## O que foi revisado

- Recomendações profissionais com cinco depoimentos completos e fotos reais individuais, distribuídos em duas colunas, com o último depoimento em faixa horizontal no desktop.
- Todas as quatro capas dos vídeos numeradas de 01 a 04. Sem imagem do primeiro vídeo.
- Removida a seção de cases genéricos "Projetos e experiências"; navegação e links atualizados para não apontar para conteúdo excluído.
- Refinadas as interações de menu, vídeos, painel editorial, experiência e rolagem; efeitos respeitam movimento reduzido e têm alternativa nativa caso o GSAP não carregue.
- Currículo original em `assets/curriculo-rafael-borges.pdf` e e-mail `rafael._borges@icloud.com` mantidos.

## Publicação

Envie os arquivos de **dentro** desta pasta diretamente para a raiz do repositório público `borjaorafa/portfolio-rafael-borges` e mantenha a pasta `assets`. Em Settings → Pages, escolha Deploy from a branch, `main`, `/(root)`.

Este pacote não foi publicado automaticamente. As cinco recomendações foram transcritas dos prints fornecidos pelo usuário; as fotos foram recortadas como avatares individuais, sem utilizar os prints integrais como imagens na página.
